# 리프트바운드 서버 — Oracle Cloud 무료 배포 가이드

목표: `https://<도메인>` 하나로 **설치 없이 브라우저 접속** → 회원가입 → 로비 대전. 월 0원.

## 1. VM 만들기 (Oracle 콘솔, 5분)

1. ≡ 메뉴 → **Compute → Instances → Create instance**
2. Image: **Ubuntu 24.04** (Canonical)
3. Shape: **Ampere (VM.Standard.A1.Flex)** — OCPU 2 / 메모리 12GB면 충분 ("Always Free eligible" 표시 확인)
   - A1 용량 부족(Out of capacity) 오류가 나면: OCPU 1로 줄이거나, **VM.Standard.E2.1.Micro**(AMD)로 대체, 또는 며칠 뒤 재시도
4. **SSH keys: "Generate a key pair" → private key 다운로드** (다시 못 받습니다! 안전한 곳에 보관)
5. 네트워크는 기본값(새 VCN, public IP 할당) 그대로 → **Create**
6. 생성 후 인스턴스 화면에서 **Public IP** 메모

## 2. 방화벽 열기 (Oracle 콘솔)

인스턴스 → Virtual cloud network 링크 → **Security Lists → Default Security List → Add Ingress Rules**:

| Source CIDR | Protocol | Port |
|---|---|---|
| 0.0.0.0/0 | TCP | 80 |
| 0.0.0.0/0 | TCP | 443 |

## 3. DuckDNS 도메인 연결

https://www.duckdns.org 로그인 → 서브도메인 생성(예: `riftbound-sim`) → **current ip 칸에 VM Public IP 입력** → update ip.
(VM의 IP는 고정이라 한 번만 설정하면 됩니다)

## 4. 서버 설치 (VM에 접속해서 한 줄)

Windows PowerShell에서:
```
ssh -i <다운받은 키 경로> ubuntu@<Public IP>
```
접속된 VM 안에서:
```
bash <(curl -fsSL https://raw.githubusercontent.com/misakila58/riftboundKr/master/deploy/setup-vm.sh) riftbound-sim.duckdns.org 접속코드
```
- `접속코드`는 오픈톡방 사람들만 가입하게 하는 암호 — 생략하면 완전 공개
- 3~5분 뒤 `✅ 완료!`가 뜨면 브라우저에서 `https://riftbound-sim.duckdns.org` 접속 확인

## 5. 이후 운영

- **게임 업데이트 배포**: VM에서 `bash <(curl -fsSL https://raw.githubusercontent.com/misakila58/riftboundKr/master/deploy/update.sh)` 한 줄
  → 웹 접속자는 **새로고침만 하면 전원 최신 버전** (버전 불일치 원천 차단)
- 계정·덱 데이터: `/opt/riftbound/data/db.json` (업데이트해도 보존됨). 가끔 백업 권장:
  `scp -i <키> ubuntu@<IP>:/opt/riftbound/data/db.json .`
- 접속 코드 변경: VM에서 `echo 새코드 | sudo tee /opt/riftbound/access-code.txt` (30초 내 자동 반영)
- 상태 확인: `systemctl status riftbound` / 로그: `journalctl -u riftbound -f`
