# 방 코드 시그널링 서버 (선택 사항)

**대부분은 이걸 배포할 필요가 없습니다.** 클라이언트는 기본적으로 공개 MQTT 브로커를 써서
6자리 방 코드 연결을 처리하므로, 아무 설정 없이 바로 동작합니다.

이 폴더는 그 공개 브로커가 불안정하거나 막혀 있을 때를 위한 **직접 띄우는 대안**입니다.
Cloudflare 무료 플랜에서 돌아가며, 실사용 비용은 사실상 0입니다
(Durable Objects 무료 한도: 하루 10만 요청 — 한 번 연결에 요청 2건 정도 씁니다).

## 무엇을 하는 서버인가

- 방 코드로 만들어진 "방"에서 **offer/answer를 한 번 전달**하고 끝냅니다.
- 게임 데이터는 지나가지 않습니다. 연결이 맺어지면 클라이언트가 소켓을 바로 닫습니다.
- 오가는 내용은 클라이언트가 **방 코드로 유도한 키로 암호화**해서 보내므로 서버는 내용을 모릅니다.
  방 이름도 코드의 해시라, 서버 로그만으로는 코드를 알 수 없습니다.
- 계정·덱·카드 데이터와는 무관합니다. `server/server.js`(로비 서버)와도 별개입니다.

## 배포 (10분)

```bash
npm install -g wrangler
```

```bash
wrangler login
```

```bash
cd server/signal-worker && wrangler deploy
```

배포가 끝나면 이런 주소가 나옵니다.

```
https://riftbound-signal.<내계정>.workers.dev
```

## 클라이언트에 연결하기

1. 게임 실행 → **👥 친구와 직접 대전** 화면
2. 맨 아래 **⚙ 고급** 펼치기
3. **시그널링 서버 주소**에 위 주소를 붙여넣기 (`https://` 그대로 넣어도 됩니다 — 자동으로 `wss://`로 바꿉니다)

주소는 이 컴퓨터에 저장됩니다. **두 사람 모두** 같은 주소를 넣어야 서로를 찾을 수 있습니다.
한쪽만 넣으면 서로 다른 채널을 보게 되어 연결되지 않습니다.

## 잘 되는지 확인

브라우저로 배포 주소를 열었을 때 `riftbound signal: ok` 가 보이면 정상입니다.

## 비용을 아예 안 쓰고 싶다면

배포하지 마세요. 기본값(공개 브로커)이 그대로 쓰이고, 그것도 안 되면
**⚙ 고급**의 *초대 코드 직접 교환*으로 서버 없이 연결할 수 있습니다.
