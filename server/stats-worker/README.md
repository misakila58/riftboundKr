# 익명 사용 통계 서버 (선택 사항)

게임이 얼마나 플레이되는지와 **덱 조합별 승률**을 파악하기 위한 집계 서버입니다.
Cloudflare 무료 플랜에서 돌아가며, 배포하지 않으면 통계 기능 자체가 꺼진 채로 동작합니다.

## 무엇을 세고, 무엇을 안 세나

세는 것 — **숫자뿐입니다.**

- 모드별(봇전·핫시트·친구 대전·서버 대전) 게임 시작/종료 판수
- 평균 턴 수, 중도 이탈 비율
- 덱 조합별 승률 — **전설 번호 + 선발 챔피언 번호**만 사용 (공개 카드 정보)
- 하루에 앱을 켠 횟수, 버전 분포

**세지 않고, 받지도, 저장하지도 않는 것**

- IP 주소 — 워커가 요청 헤더를 아예 읽지 않습니다
- 설치 ID·기기 ID — 클라이언트가 만들지도 보내지도 않습니다
- 닉네임·계정·덱 이름·덱 전체 목록·채팅·리플레이
- 개별 요청 기록 — 도착 즉시 카운터에 +1 하고 버립니다
- 정확한 시각 — 날짜(YYYY-MM-DD)까지만 남깁니다

그래서 저장되는 것은 `2026-09-03에 봇전이 12판 시작됐다`, `카이사/다리우스가 애니/고집쟁이에게 7승 3패` 같은
**집계 숫자**뿐이며, 특정 개인을 알아볼 수 있는 정보가 남지 않습니다.

"오늘 앱을 켰다" 신호도 식별자 없이 셉니다 — 클라이언트가 마지막 전송 날짜를 **자기 컴퓨터에만** 저장해 두고
날짜가 바뀐 첫 실행에만 한 번 보내므로, 서버는 개수만 알 뿐 누가 보냈는지 알 수 없습니다.

이용자는 첫 화면의 **📊 익명 통계** 버튼으로 언제든 끌 수 있습니다.

## 배포

```bash
npm install -g wrangler
```

```bash
wrangler login
```

```bash
cd server/stats-worker && wrangler deploy
```

배포되면 `https://riftbound-stats.<내계정>.workers.dev` 형태의 주소가 나옵니다.

## 클라이언트에 연결

`client/web/js/stats.js` 맨 위의 `URL` 에 그 주소를 넣고 빌드합니다.

```js
const STATS = {
  URL: 'https://riftbound-stats.내계정.workers.dev',
```

**비워 두면 통계 기능이 완전히 꺼집니다** — 버튼도 숨겨지고 아무 요청도 나가지 않습니다.

## 집계 보기

```bash
node tools/stats-report.js https://riftbound-stats.내계정.workers.dev
```

```bash
node tools/stats-report.js https://riftbound-stats.내계정.workers.dev --days 7 --min 5
```

`--days N` 최근 N일만 · `--mode p2p` 특정 모드만 · `--min N` 매치업 최소 표본 수(기본 3)

원본 JSON은 `<주소>/s` 로도 볼 수 있습니다.

## 알아둘 점

- 온라인·친구 대전은 **좌석 0(방장)만 보고**합니다. 양쪽이 보고하면 같은 판이 두 번 세어지기 때문입니다.
  방장이 결과 확정 전에 창을 닫으면 그 판은 집계에서 빠집니다.
- 봇전은 상대 덱이 무작위/대회 덱이라 사람 간 메타와 성격이 다릅니다. 리포트에서 `--mode` 로 나눠 보세요.
- 조회 주소(`/s`)는 공개입니다. 집계 숫자만 있어 민감하지 않지만, 감추고 싶으면
  `worker.js` 의 GET 분기에 토큰 확인을 추가하세요.
