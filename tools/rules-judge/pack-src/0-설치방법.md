# 리프트바운드 룰 판정 팩 — 설치 방법 (5분)

이 폴더의 파일을 **AI 프로젝트에 업로드**하고, `1-지침.md`의 내용을 **프로젝트 지침 칸에 붙여넣기**만 하면 됩니다. 프로그램 설치나 스크립트 실행은 없습니다.

## Claude (claude.ai) 프로젝트

1. claude.ai → 왼쪽 **프로젝트** → **새 프로젝트** (이름 예: 리프트바운드 룰 판정)
2. 오른쪽 **프로젝트 지식(Project knowledge)** → **+ 파일 추가** → 이 폴더의 `룰북-…txt`, `카드.md`, `판정-…md` 파일을 **전부** 올립니다 (여러 개 한 번에 선택 가능)
3. **프로젝트 지침 설정(Set project instructions)** → `1-지침.md` 내용을 통째로 복사해 붙여넣고 저장
4. 이 프로젝트 안에서 새 대화를 열고 질문합니다. 예: "천 개 꼬리의 감시자로 -3 받은 유닛에 +2 버프를 주면 위력이 몇이 돼?"

## ChatGPT 프로젝트 또는 나만의 GPT

**프로젝트**: ChatGPT → 왼쪽 **프로젝트** → **새 프로젝트** → **파일 추가**로 위와 같은 파일을 전부 올리고 → **지침(Instructions)** 에 `1-지침.md` 내용을 붙여넣기.

**나만의 GPT(GPTs)**: 탐색 → 만들기 → **구성** 탭 → 지침 칸에 `1-지침.md` 붙여넣기 → **지식(Knowledge)** 에 파일 업로드(최대 20개) → 기능에서 **코드 인터프리터/파일 검색** 켜기 → 저장.
