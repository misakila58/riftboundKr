1. 시작하기

  1. RiftboundSim-portable.exe를 내려받아 더블클릭합니다. 설치 과정이 없으며 실행하면 바로 첫 화면이 뜹니다.
  2. Windows가 "PC를 보호했습니다"(SmartScreen) 경고를 띄우면 — 서명되지 않은 개인 제작 프로그램이라 나오는 표준 경고입니다 — 추가 정보 → 실행을 누르면 됩니다.
  3. 처음이라면 첫 화면의 🎓 튜토리얼부터 시작하세요. 25단계로 규칙 전체를 직접 플레이하며 배웁니다.
내 데이터는 어디에? 닉네임·덱은 내 컴퓨터에만 저장됩니다. 리플레이는 문서\RiftboundSim\Replays 폴더에 .rbr 파일로 저장됩니다.

2. 게임 모드

혼자🎓 튜토리얼 고정 덱과 연습 봇을 상대로 턴 구조부터 결전·득점까지 25단계로 배웁니다. 완료 후 자유 연습도 가능합니다.
혼자🤖 BOT 대전 난이도 5단계 봇과 대전합니다. 상대 덱으로 실제 대회 우승 덱을 고를 수도 있습니다.
둘이 · 원격👥 친구와 직접 대전 서버 없이 초대 코드만 주고받아 P2P로 연결합니다. 계정 불필요 — 가장 간단한 온라인 대전.
둘이 · 원격🌐 서버 접속 방장이 서버 프로그램을 켜고 주소를 공유하면, 접속해서 회원가입 후 로비에서 대전합니다. 상시 운영에 적합.
둘이 · 한 PC💺 오프라인 핫시트 한 화면에서 두 사람이 번갈아 플레이합니다. 양쪽 손패가 모두 보이므로 규칙 연습·복기에 좋습니다.

친구와 직접 대전 (초대 코드) 순서

  1. 두 사람 모두 프로그램 실행 → 👥 친구와 직접 대전 선택
  2. 방장: [초대 코드 만들기] → 코드를 카톡·디스코드로 전송
  3. 상대: 코드를 붙여넣고 [응답 코드 만들기] → 응답 코드를 방장에게 회신
  4. 방장: 응답 코드를 붙여넣고 [연결하기] → 자동으로 게임 시작
연결이 안 되면 일부 사내망·특수 공유기에서는 P2P가 막힐 수 있습니다. 그 경우 서버 접속 방식을 사용하세요. 온라인 대전에서는 항상 내 진영이 화면 아래(6시)에 표시됩니다.

5. 핵심 룰 요약

8점을 먼저 얻으면 승리합니다. 점수는 전장에서만 나옵니다.

개념설명
턴 구조각성(탈진 해제) → 시작(유지 득점) → 전개(룬 2개) → 드로우 → 행동 단계
자원에너지 = 룬을 탈진(다음 턴 복구) · 힘 = 룬을 룬 덱으로 재활용. 비용은 자동 지불
정복전장의 통제권을 새로 얻으면 +1점 (전장당 턴에 1번)
유지내 턴 시작까지 전장을 지키면 +1점 — 단, 유닛이 주둔해야 합니다. 비면 무주공산(통제 해제)
결전전장에 유닛이 들어가면 열리는 대응 창. [행동]/[반응] 카드가 체인에 쌓이고, 양측 패스 시 나중 것부터 해결
전투양측 위력(⚔) 합계만큼 서로에게 동시에 피해 배분. 방어 성공은 득점 없음
마지막 1점7점 이후의 정복은 그 턴 모든 전장을 득점했을 때만 인정 (아니면 카드 1장 대체) — 유지는 제한 없음
번아웃덱이 떨어지면 폐기장을 덱으로 되돌리고 상대가 +1점
글보다 튜토리얼. 위 내용 전부를 튜토리얼에서 직접 두면서 배울 수 있습니다 — 15분이면 충분합니다.

6. 봇 난이도

단계플레이 스타일
😊 초보무작위 위주로 둡니다. 규칙을 익히는 용도
🙂 중수대상·비용·손패를 따져 둡니다. 큰 실수는 하지 않습니다
😎 고수전투 계산과 승점 레이스를 읽고 공격·점거 가치를 판단합니다
😈 초고수한 턴에 여러 갈래로 압박하고 카드 능력·숨김 카드까지 활용합니다
👹 초고수 (내 패를 고려함)초고수와 같되 당신의 손패와 덱을 봅니다 — 가장 강하지만 공정하지 않습니다

상대 덱으로 🏆 실제 대회 우승 덱을 고르면 메타 덱을 상대로 연습할 수 있습니다.

7. 덱 만들기

  • 첫 화면 🗂 내 덱 관리 → 새 덱. 전설을 고르면 [자동 완성]으로 40장이 채워집니다 — 그대로 써도 되고 바꿔도 됩니다.
  • 카드 풀은 코스트순·가나다순·세트순으로 정렬할 수 있고, 검색·타입 필터·전설 영역 필터를 지원합니다.
  • 구성: 메인 덱 40장(같은 카드 3장까지) + 룬 12개 + 전장 3곳 + 선발 챔피언.
  • 시그니처 카드(티버스, 최후의 전사, 최후의 섬광, 결정타)는 같은 챔피언의 전설 덱에만 넣을 수 있습니다 — 예: 티버스는 애니 전설 덱 전용.
  • KR 밴 리스트가 표시되며, 밴 적용 대전에서는 해당 카드를 쓸 수 없습니다.

8. 리플레이

  • 경기가 끝나면 자동 저장됩니다. 진행 중에도 Esc → 리플레이 저장으로 남길 수 있습니다.
  • 첫 화면 🎬 리플레이 보관함에서 재생 — 양측 손패가 모두 공개되고, 슬라이더·재생 속도·턴 점프로 복기할 수 있습니다.
  • 파일은 문서\RiftboundSim\Replays\*.rbr에 저장되며, 파일을 친구에게 보내면 상대도 보관함에서 열어 볼 수 있습니다.

9. 문제 해결

증상해결
