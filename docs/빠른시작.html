리프트바운드 시뮬레이터 — 빠른 시작

라이엇 TCG 리프트바운드 한글 대전 시뮬레이터입니다. Origins(298장)와 증명의 전장(24장), 총 322장을 전부 자동 처리합니다. 비공식 팬 프로젝트이며 무료입니다.

1. 접속하기

https://riftboundsimkr.duckdns.org
가장 쉬움 🌐 브라우저로 바로 위 주소를 열면 끝. 설치도 업데이트도 필요 없고 항상 최신 버전입니다. PC·모바일 모두 됩니다.
설치형 💻 데스크톱 앱 RiftboundSim-portable.exe를 받아 실행합니다. 카드 그림이 앱에 들어 있어 로딩이 빠릅니다. 새 버전이 나오면 다시 받아야 합니다.
설치 없이 👥 친구와 둘이 서버 없이 6자리 방 코드만 주고받으면 바로 연결됩니다. 방장이 코드를 만들어 카톡으로 보내면 끝.

3. 기본 조작

카드·유닛

  • 좌클릭 — 낼 수 있는 행동 메뉴
  • 드래그 — 유닛을 전장으로 이동
  • 우클릭 / Alt+클릭 — 카드 확대
  • 마우스 올리기 — 옆 패널에 상세

자원·기타

  • 룬 클릭 — 에너지/힘을 미리 풀에 올리기
  • ESC — 메뉴 (항복·패스·나가기)
  • 🔍 화면 배율 — 70~140% 조절
  • 🎬 리플레이 — 저장·재생·전달
자동 / 수동 모드 — 기본은 자동입니다. 322장 전부 효과가 자동 처리되니 규칙을 몰라도 됩니다. 직접 판정하며 연습하고 싶다면 방을 만들 때 자동 규칙 처리 체크를 해제하세요.

4. 게임 흐름 30초 요약

먼저 8점을 얻으면 승리합니다. 점수는 전장에서 나옵니다.

  • 정복 — 전장을 새로 차지하면 1점
  • 유지 — 내 턴 시작에 이미 차지하고 있으면 1점

턴은 이 순서로 흐릅니다.

① 각성내 룬·유닛·도구가 모두 준비됨
② 개시차지 중인 전장에서 유지 득점
③ 전개룬 2장을 깝니다 (자원)
④ 드로우카드 1장
⑤ 행동카드 내기 · 유닛 이동 · 능력 사용 — 자유롭게
⑥ 종료피해·기절이 정리되고 상대 턴으로

내 유닛이 상대 전장에 들어가면 결전이 열립니다. 양쪽이 번갈아 카드를 내며 응수하다가, 둘 다 넘기면 전투가 해결됩니다.

룬정확히 12개
전장정확히 3개

덱이 없어도 됩니다. 🎲 무작위 자동 덱으로 바로 시작하거나, 🏆 대회 우승 덱에서 실제 입상 덱을 가져오면 됩니다.

다른 일러스트 고르기 (신규)

같은 카드의 다른 그림 54종이 들어 있습니다. 덱 편집기에서 카드를 우클릭하면 확대 화면에 일러스트 선택이 나옵니다. 고른 그림은 덱과 함께 저장되고 대전 중 상대 화면에도 그대로 보입니다. 효과는 완전히 같은 카드라 3장 제한에도 영향이 없습니다.

6. 잘 안 될 때

증상해결

카드 그림이 안 보임인터넷 연결을 확인하세요. 데스크톱 앱은 그림이 안에 들어 있어 영향을 덜 받습니다
