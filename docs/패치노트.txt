■ v1.0.36 (2026-08-27)
- 이동 모드에서 기지를 클릭해도 이동되지 않던 문제 수정 — 전장처럼 기지도
  목적지로 클릭 가능
- 화면 배율 기능 추가: 첫 화면의 "화면 배율 조절" 버튼과 게임 중 ESC 메뉴에서
  70~140% 배율을 즉시 적용·저장
- 낮은 해상도에서 시작 화면이 잘리고 스크롤이 안 되던 문제 수정
- 하단 법적 고지문이 화면 아래 내용(버튼·카드 목록)을 가리던 문제 수정 — 모든 화면 공통

■ v1.0.34 (2026-08-26)
- 효과에 의한 이동(매혹, 블리츠크랭크, 야스오 전설, 물결을 바꾸는 자 등)이
  이동 횟수와 이동 트리거에 반영되지 않던 문제 수정
  → 케인(2회 이동 시 피해 무시), 야스오(3회째 이동 시 득점) 정상 동작

■ v1.0.33 (2026-08-26)
- 채팅을 게임 로그와 분리된 전용 팝업으로 변경 — 상대 메시지가 오면 채팅 버튼에
  빨간 점으로만 알리고, 팝업에서 대화 이력을 모아 볼 수 있음
- 덱 편집: 덱에 넣은 카드를 우클릭/Alt+클릭하면 제거되지 않고 카드 상세(확대) 표시
- 촛불 밝힌 성소: 원문대로 덱 위 2장을 동시에 확인하도록 수정
  (기존엔 첫 장을 되돌리지 않으면 둘째 장을 보여주지 않았음)

■ v1.0.32 (2026-08-25)
